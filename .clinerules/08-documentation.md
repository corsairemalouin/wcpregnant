# Documentation

- Maintenir la documentation **en français** (sauf `ARCHITECTURE.md`, `README-DEPLOY.md`, `k8s/README.md` déjà en anglais : rester dans leur langue).
- Toute amélioration technique (nouvelle classe, refactor, endpoint) doit être reflétée dans le document concerné : `ARCHITECTURE.md` (design, SOLID, couches), `README.md` (usage), `SETUP-GUIDE.md` (prérequis).
- Format : titres hiérarchiques, tableaux pour les comparaisons, exemples de code fonctionnels, aucune section vide.
- Ne pas dupliquer : renvoyer aux fichiers existants plutôt que recopier un contenu.
- Mettre à jour la date/section "État d'avancement" quand le projet progresse.
